# Python ETL Pipeline

## Project Overview
This project demonstrates a basic ETL (Extract, Transform, Load) pipeline using Python and Pandas.

## Technologies Used
- Python
- Pandas
- CSV

## Project Workflow
1. Extract sample employee data.
2. Transform employee salary data by increasing salaries by 10%.
3. Load the transformed data into a CSV file.

## How to Run
1. Install Python.
2. Install dependencies:
   pip install -r requirements.txt
3. Run the pipeline:
   python etl_pipeline.py

## Expected Output
The pipeline transforms employee salary data and saves it to processed_data.csv.
